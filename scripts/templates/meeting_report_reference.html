Données structurées — tâches et événements

Le JSON ci-dessous regroupe les tâches et les événements. Remplacez les exemples par les éléments extraits du transcript. Utilisez null lorsqu’une personne, une date ou un parent ne sont pas précisés.

{
  "tache-1": {
    "type": "tache",
    "parent": null,
    "completed": false,
    "argv": {
      "titre": "[Titre de la tâche]",
      "qui": "[Responsable ou null]",
      "quand": "[Date ISO AAAA-MM-JJ ou null]",
      "statut": "a_faire"
    }
  },
  "tache-2": {
    "type": "tache",
    "parent": "tache-1",
    "completed": false,
    "argv": {
      "titre": "[Sous-tâche]",
      "qui": null,
      "quand": null,
      "statut": "a_faire"
    }
  },
  "evenement-1": {
    "type": "evenement",
    "parent": null,
    "completed": false,
    "argv": {
      "titre": "[Titre de l’événement]",
      "date": "[Date ISO AAAA-MM-JJ ou null]"
    }
  },
  "evenement-2": {
    "type": "evenement",
    "parent": "evenement-1",
    "completed": false,
    "argv": {
      "titre": "[Événement lié]",
      "date": null
    }
  }
}

Valeurs de statut suggérées : a_faire, en_cours, termine, bloque, non_precise. Mettre completed à true uniquement si la tâche est explicitement terminée.
